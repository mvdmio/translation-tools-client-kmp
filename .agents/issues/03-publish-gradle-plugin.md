# Gradle plugin is not published

Category: enhancement
Status: ready-for-human

**Source:** jewel-app colleague, 2026-08-18

## Summary

`io.mvdm.translationtools.plugin` is not on the Gradle Plugin Portal or Maven Central. Consumers must copy `gradle/translationtools-plugin` and attach it with `includeBuild`. The README already says this.

## Why it matters

jewel-app can vendor the plugin. That works, but it is extra setup and it puts our plugin build on their build classpath. The plugin currently depends on `implementation(libs.kotlin.gradle.plugin)` at Kotlin 2.1.20. Via `includeBuild` that lands next to jewel-app's Kotlin Gradle plugin 2.3.21.

## What we verified

- Plugin Portal: `https://plugins.gradle.org/plugin/io.mvdm.translationtools.plugin` → not found.
- Maven Central marker `io.mvdm.translationtools.plugin.gradle.plugin` → 404.
- [`README.md`](../../README.md) documents composite-build setup and says the plugin is not yet published.
- [`gradle/translationtools-plugin/build.gradle.kts`](../../gradle/translationtools-plugin/build.gradle.kts) registers the plugin id but has no `maven-publish` / Plugin Portal publishing plugin and no publish workflow.
- Plugin dependency is `implementation(libs.kotlin.gradle.plugin)` at 2.1.20, not `compileOnly`.

## Suggested fix

1. Publish the plugin to the Gradle Plugin Portal (and/or Maven Central).
2. Change the Kotlin Gradle plugin dependency to `compileOnly` so an `includeBuild` consumer does not pull Kotlin 2.1.20 onto the build classpath.
3. Keep README install snippets in sync.

Publishing needs a Plugin Portal account and CI secrets. Wiring the build is agent work. The first publish is a person.
